# ChromaShift: Algorithmic Color Grading & LUT Playground

## Purpose
ChromaShift is a professional-grade, browser-based color grading workstation and LUT creator. Designed for photographers, filmmakers, and UI designers, it allows users to manipulate imagery with precise tone curves, color wheels, split toning, and film emulation presets entirely client-side using HTML5 Canvas pixel manipulation.

## Features
- **Real-time Canvas Engine**: High-performance pixel grading pipeline supporting exposure, contrast, highlights, shadows, saturation, vibrance, temperature, and tint.
- **Primary Color Wheels**: Lift, Gamma, and Gain controls with interactive color picker rings and luminance adjusters.
- **Split Toning**: Independent highlight and shadow hue & saturation controls with balance adjustment.
- **Cinematic Film Presets**: Instant one-click emulations including Technicolor, Bleach Bypass, Cross Processing, Neo Noir, and Cyberpunk.
- **Post-Processing Effects**: Adjustable film grain, vignetting, and halation glow.
- **Live Histogram**: Real-time RGB frequency analysis.
- **Comparison Tools**: Interactive 'Hold to Compare' original image inspection.
- **Export Capabilities**: Download graded images as high-res JPEGs or export custom looks as standard `.cube` 3D LUT files.

## Local Run Instructions
1. Download or clone the repository containing `index.html`, `style.css`, and `script.js`.
2. Open `index.html` directly in any modern web browser.

*Note: This is a 100% static client-side web application with zero external dependencies, build tools, or network requests.*
